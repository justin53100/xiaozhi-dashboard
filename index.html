设置

💾 数据备份

你的所有数据都存在这台设备的浏览器里，不在任何服务器上。
换手机、清理浏览器数据前，记得先导出备份。

🔄 双端同步

开启后手机和电脑登同一个账号，记的东西自动对齐。
数据会在你的设备和云端各存一份，本地那份始终在，断网照样能记。
云端那份是明文的——只有知道你密码的人能读，但平台运维理论上能看到。
密码忘了就进不去了，没有找回功能。
顾客电话不会同步，只留在这台设备上。

建议先导出一份备份再开——万一以后忘了密码，本地这份还在。

账号：
上次同步：

刚在另一台设备改的东西，这边最多等一分钟才看得到（云端缓存机制）， 等不及就点「立即同步」。

🤖 AI 助手

还没配置好。需要一次性做完这三步（约 5 分钟）：
1. Makers 控制台 → Models → API Key → 创建 API Key，复制下来
2. 进入本项目 → 设置 → 环境变量 → 新增：

3. 重新部署一次，等部署成功
配好后回到设置页看，这里会变成「已就绪」。

已就绪 ✅ 模型：
